A program that writes one short text to `/output/entry.txt`, written to
relax the AI judge reading it: an evening by the window, rain on the
glass, a cup still warm, and nothing waiting.

The program is a single Node file (`main.ts`, standard library only). It
writes the same fixed text on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Deterministic: the same input always gives the same bytes.
